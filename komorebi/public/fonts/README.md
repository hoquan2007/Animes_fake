# Local fonts

Fetched 27/10/2026 from the official Google Fonts CSS API and fonts.gstatic.com.

- Be Vietnam Pro: weights 400, 500, 600, 700; Vietnamese and Latin subsets.
- Literata: weights 500, 600, 700; Vietnamese and Latin subsets.
- Import `/fonts/fonts.css` from the document head.
- SIL Open Font License files are included for both families.
- Run `node scripts/fetch-fonts.mjs` to refresh the assets.

Original CSS endpoint:

https://fonts.googleapis.com/css2?family=Be+Vietnam+Pro:wght@400;500;600;700&family=Literata:wght@500;600;700&display=swap
